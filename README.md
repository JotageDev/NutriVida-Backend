# NutriVida Back-End

API do projeto NutriVida desenvolvida com Node.js, Express e PostgreSQL.

## Instalação

1. Renomeie `.env.example` para `.env`.
2. Configure os dados do PostgreSQL no `.env`.
3. Instale as dependências:

```bash
npm install
```

4. Inicie em modo de desenvolvimento:

```bash
npm run dev
```
